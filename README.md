# Checkers-AI


Игра в шашки на Python с графическим интерфейсом Tkinter. Можно играть против ИИ, который использует алгоритм Minimax с альфа-бета-отсечением.

# Запуск

1. Требуется Python 3 и Tkinter.
2. Запустите файл checkers.py используя предпочитаемую IDE. Тестровано на VS code.
3. Выберите сложность и нажмите Play.

# Управление

1. Нажмите на свою шашку.
2. Нажмите на клетку, куда хотите её переместить.
3. Игра завершится, когда у одной из сторон не останется шашек.

# Сложность ИИ

Easy- глубина поиска 1.
Medium-глубина поиска 5.
Hard- глубина поиска 10.



# Реализация

Checker - правила ходов, генерация возможных позиций и алгоритм ИИ.
CheckersGame - графический интерфейс и ход игры.

Доска хранится в виде матрицы 8×8. ИИ оценивает позиции по количеству шашек и дамок. Для расчёта хода ИИ установлен лимит в 20 секунд.

# Известные ограничения

Множественное взятие игроком реализовано не полностью. На высокой сложности ИИ может долго рассчитывать ход.
